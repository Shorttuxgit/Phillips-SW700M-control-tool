# Phillips-SW700M-control-tool
As the Phillips SW700M Spotify Multi room speakers have been discontinued and the app no longer functioning on new phones, I have created a tool (yes with AI I don't have infinite time i'm afraid) to scan your network for such speakers and give easy and simple commands to control the speakers with. So you can bring back grouping and can rename them.
The tool automatically downloads the zeroconf python package.

## Supported Operating Systems
* Ubuntu - Tested Fully Working
* Windows - Untested

## Setup
Ensure system is up to date and that the latest version of Pip is installed. Running main.py installs all dependencies automatically.
